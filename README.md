| Tool | What It Is |
|------|-----------|
| **Maven** | Java build automation and dependency management |

| **Git** | Distributed version control |
| **Docker** | Container platform for building, running, and shipping apps |
| **Terraform** | Infrastructure as Code (IaC) |
